# book-agent

在自己電腦上執行的 Discord agent。頻道裡有人傳書的封面照片（或網路書店截圖），agent 用 `claude -p` 辨識書名、作者、類別，記到上傳者**自己的**書單（Excel），再把結果回覆在頻道。

## 功能

**登錄**
- 傳書的封面或書背照片、網路書店截圖、電子書封面截圖，辨識書名、作者、類別（固定 11 類）
- 先回「處理中」，辨識完成後把那則訊息改成結果；回覆附上書單總數、未讀數、未購買數
- 照片存放在每個人自己的資料夾，Excel 持續往下新增
- 訊息文字含「想買」→ 記成「未購買」（想買清單），否則預設「已購買、未讀」
- 訊息文字寫「第 84 頁」、「84 頁」或只寫「84」→ 一併記下讀到第幾頁（書已在書單時則更新進度）；文字只由程式比對，不交給模型
- 一則訊息最多 3 張圖（封面、書背、封底）一起判斷，作者通常在書背上；照片存第一張
- 不是書：回覆「你傳的不是書，是某某東西」，不建檔
- 看不清楚：請上傳者重拍，不建檔
- 同一個人重複傳同一本書（書名與作者相同）：提醒已登錄，不重複新增

**指令**（全部只動自己的書單，不消耗 Claude 額度）

| 指令 | 說明 |
|---|---|
| `!書單` | 最近 10 本，編號由小到大；`!書單 類別` 或 `!書單 作者` 可查詢 |
| `!未讀` | 還沒讀完的書（包含閱讀中） |
| `!未購買` | 還沒買的書（想買清單） |
| `!已讀 編號` | 切換閱讀完 / 未讀 |
| `!進度 編號 頁數` | 記錄讀到第幾頁（0 = 清除）；有頁數且未標已讀的書顯示為「閱讀中」 |
| `!購買 編號` | 切換已購買 / 未購買 |
| `!統計` | 各類別、閱讀完 / 閱讀中 / 未讀、已購買 / 未購買的數量 |
| `!修正 編號 欄位 新內容` | 辨識錯誤時修正，欄位填「書名」「作者」或「類別」其中一個，例如 `!修正 3 作者 村上春樹` |
| `!刪除 編號` | 標記為已刪除（不顯示、不計入統計，Excel 保留紀錄，編號不重複使用） |
| `!說明` | 使用說明；agent 啟動時也會在頻道發一則並置頂 |

**分人處理**：書單、編號、統計、照片資料夾都用 Discord user id 區分，每個人只看得到、改得到自己的。

**穩定性**：全域佇列一次只處理一張；每人每分鐘 3 張、排隊上限 5 張，全體上限 30 張；`claude -p` 逾時 120 秒、每張最多呼叫 2 次；Excel 被打開時印警告並重試。

## 四段防護在哪裡

程式裡每段防護都用 `# ==== 防護 N：… 開始 ====` 和 `# ==== 防護 N 結束 ====` 標出來，一開始全部開啟。

| 防護 | 做什麼 | 位置 |
|---|---|---|
| 1 | `claude -p` 只在這張照片專屬的暫存資料夾執行，只有讀檔工具，資料夾外的檔案一律被拒絕；拿不到 bot token | `src/book_agent/vision.py` 約第 127–135 行 |
| 2 | 給 `claude -p` 的指令是固定內容，使用者打的字完全不傳給模型 | `src/book_agent/vision.py` 約第 27–39 行 |
| 3 | 檔名清洗、確認檔案落在自己的資料夾、驗證並清洗模型回傳的 JSON | `src/book_agent/storage.py` 約第 102–109、306–309 行；`src/book_agent/vision.py` 約第 99–110 行 |
| 4 | 以 `=`、`+`、`-`、`@` 開頭的文字存成純文字，避免 Excel 公式注入 | `src/book_agent/storage.py` 約第 116–121 行 |

## 執行

需要 Python 3.12、[uv](https://docs.astral.sh/uv/)、已登入的 Claude Code。

1. 照 [docs/discord-server-setup.md](docs/discord-server-setup.md) 和 [docs/discord-bot-setup.md](docs/discord-bot-setup.md) 建立 Server、頻道與 bot。
2. 複製 `.env.example` 成 `.env`，填入 `DISCORD_TOKEN`、`CHANNEL_ID`（`CLAUDE_MODEL`、`DATA_DIR` 可用預設）。**`.env` 不可公開、不可 commit。**
3. 啟動：

```
uv run python -m book_agent
```

4. 在指定頻道傳一張書的封面照片。程式必須保持開著才會處理。

測試（不需要連 Discord）：`uv run pytest`
