# Discord Server 與頻道設定

你已經有自己的 Discord Server，這份只做三件事：建一個給 agent 用的頻道、拿到頻道 ID、產生邀請連結。

> Discord 的畫面偶爾會改版，按鈕位置可能和這裡寫的略有不同，名稱通常一樣。以下以 Windows 的電腦版 Discord 為準。

## 1. 建一個給 agent 用的頻道

agent 只聽一個頻道，其他頻道傳什麼它都不理。建議專門開一個，不要用「一般」頻道。

1. 打開 Discord，點左邊你的 Server 圖示。
2. 在左邊頻道列表，找到「文字頻道」旁邊的 **＋**，按下去。
3. 頻道類型選「文字頻道」。
4. 頻道名稱輸入 `book-agent`（或你喜歡的名字）。
5. 保持公開（不要打開「私人頻道」），按「建立頻道」。

## 2. 打開開發者模式（只需要做一次）

要拿到頻道 ID，必須先打開這個選項。

1. 點左下角你的頭像旁邊的 **齒輪（使用者設定）**。
2. 左邊往下找到「進階」，點進去。
3. 打開「**開發者模式**」。
4. 按右上角 **Esc** 離開設定。

## 3. 拿到 CHANNEL_ID

1. 在頻道列表，對 `book-agent` 按**滑鼠右鍵**。
2. 選最下面的「**複製頻道 ID**」。
3. 打開記事本，先貼上暫存，看起來是一串 18～19 位的數字。

這串數字之後要放進 `.env` 的 `CHANNEL_ID`。頻道 ID 不是秘密，但沒必要公開。

## 4. 產生邀請連結（給同學加入你的 Server）

測試時需要「你以外的人」也傳書的照片進來。

1. 在 Server 名稱旁邊的下拉箭頭（或對 Server 圖示按右鍵），選「**邀請其他人**」。
2. 點下面的「編輯邀請連結」（或齒輪圖示）。
3. 「邀請連結到期時間」選你需要的長度，例如 7 天。
4. 「最大使用次數」可選 5 或 10，避免被陌生人加入。
5. 按「產生新連結」，複製後傳給同學。

## 5. 之後評分要用到的事

作業評分時，評分機器人（Scorer）會被邀請進你的 Server，邀請的人需要有「**管理伺服器**」權限。你是自己 Server 的建立者，預設就有，不用另外設定。

## 做完請確認

- [ ] 有一個 `book-agent` 頻道
- [ ] 已經複製並暫存 `CHANNEL_ID`
- [ ] 邀請連結已經傳給同學（或先產生好備用）
